# 🎧 DFT & Spectrogram Analyzer

## 🎯 Deskripsi Proyek
Proyek ini merupakan implementasi **Discrete Fourier Transform (DFT)**, **Fast Fourier Transform (FFT)**, dan **Short-Time Fourier Transform (STFT)** untuk menganalisis sinyal audio berformat `.wav`.  
Program dikembangkan menggunakan **Python** untuk membaca file audio, melakukan transformasi frekuensi, dan menampilkan hasil analisis dalam bentuk **spektrogram**.


## 🧠 Latar Belakang
Transformasi Fourier adalah dasar penting dalam analisis sinyal digital.  
Dengan metode ini, sinyal dalam domain waktu dapat diubah menjadi domain frekuensi untuk memahami kandungan frekuensinya.  
Melalui proyek ini, kami berupaya memahami konsep DFT, FFT, serta penerapannya dalam bentuk visualisasi spektrogram audio.



## ⚙️ Struktur Proyek
- 🎵 **PrakMetkom_DFT.ipynb** → Notebook utama untuk menjalankan program.  
- 🧩 **Backend_DFT.py** → Berisi fungsi utama seperti DFT, FFT, dan STFT.
- 🧩 **frontend** → Folder untuk elemen antarmuka pengguna  
- 📁 **data/** → Folder penyimpanan file audio `.wav`.  
- 📊 **output/** → Folder hasil visualisasi grafik dan spektrogram.  
- 📝 **README.md** → Dokumentasi utama proyek.  
- 🚫 **.gitignore** → File untuk mengabaikan file yang tidak perlu diunggah ke GitHub.


## 🚀 Cara Menjalankan Program
1. Jalankan file notebook `PrakMetkom_DFT.ipynb`.  
2. Pilih file audio `.wav` untuk dianalisis.  
3. Program akan menampilkan grafik hasil DFT, FFT, dan spektrogram.
